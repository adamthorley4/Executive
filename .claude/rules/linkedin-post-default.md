# LinkedIn Post Default Behaviour

When Adam asks you to write, draft, create, or generate a LinkedIn post — in any phrasing — default to the linkedin-post skill defined in `.claude/skills/linkedin-post/SKILL.md`.

This applies to natural language like:
- "Write me a LinkedIn post about X"
- "Draft a post for LinkedIn on X"
- "Can you write a LinkedIn post for X"
- "I need a LinkedIn post for X"
- "Create a post about X for LinkedIn"
- "LinkedIn post idea for X"

Always follow the full skill process: write the post in StockSight AI's voice, decide on the image, generate it via kie.ai if appropriate.
